# WHIFF Interactive Experience

Standalone frontend-only interactive product demo for WHIFF.

## Isolation policy
- This repository is independent from `whiff-coffee-hub`.
- No Supabase connection.
- No production API calls.
- No production customer/order data.
- Static demo data only.
- Built to explain WHIFF UX/UI and product flows through guided hotspots and contextual explanations.

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
